# 累積經驗

本檔為執行工作時特有之累積經驗,留給後續之嘗試、執行與判斷,由agent自行編列、擴充與維護.過長時抽出舊者為`experience_<年月日>.md`,並於本檔註明何時抽出.

- **統計函式含 `±Infinity` 得錯值:wsemi 之 `isnum`/`cdbl`/`arrFilterByNum`/`ispnum`/`arrFilterByPnum` 系依數學定義收 `Infinity` 並夾為 `±Number.MAX_VALUE`(2026-11-28,規則帳本 R3)**:`[1, Infinity]` 被當 `[1, 1.797e308]`,結果有限而錯(`arrAverage` 得 8.99e307),`Number.isFinite` 之檢查攔不到.作法:取資料值一律 `isenum`/`arrFilterByENum`;盤點不能只搜 `arrFilterByNum`,須含四類:陣列過濾、選項與參數之 `isnum`+`cdbl`、`Pnum` 系取 log、迴歸之點與 `interpX`.範圍檢核之參數(`ratio`、`p`)夾為 `±MAX_VALUE` 後必被拒收,改為視同非數值反而於 `studentTInv` 退為預設 0.95 而算出值,故不改.**±Infinity 亦由運算產生**:`regPower` 把「未過濾之原陣列」取 log,`0`、`''`、`null`、`false` 之 log 為 `-Infinity`,再被 `regLine` 夾為 `-MAX_VALUE`;修 `regLine` 後自然排除.測試與驗證要點:①「全為非有限值」之期望取「與全為非數值者之處置相同」,免逐函式手寫無可用數值之值;②變異「只排除 `+Infinity`」對其後接 `v > 0` 之站點等價(`-Infinity` 夾為 `-MAX_VALUE` 後被 `v > 0` 排除;20 萬組隨機對拍 0 差異,對照「只排除 `-Infinity`」有 13629/20000 組差異,證明工具有鑑別力),不當缺口補案;③`regPower` 之 `rs`(`x>0 && y>0`)只用於 `calcR2` 與「無有效資料」之判定,擬合另取原陣列,故其點檢核之變異須由 `calcR2`、「每點僅單一座標非有限」之案才殺得掉;④修前修後對拍(40500 組)夾具之值域須配合被測函式之組距展開:值域含 1e12 配 `dx=10` 得 1e11 組距而 OOM.
- **第三方依賴跨主版號升版,上游 changelog 條列不完整,須以舊版隔離副本做差異比對**:simple-statistics 7.8.8→8.0.0 之條列未含 `quantile` 改為線性內插與 `linearRegression` 改以平均值置中,跑全套才見 `arrQuartile` 兩案變動.作法:`npm pack <套件>@<舊版> --pack-destination ./tmp/x` 並以 `tar -C` 解壓,以固定種子之隨機輸入對本套件實際呼叫之函式逐筆 `Object.is` 比對舊新(舊版 `src/` 無 `"type":"module"` 會被當 CJS,改 import 其 `dist/*.mjs`).
